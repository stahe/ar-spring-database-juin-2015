    4. مقدمة إلى Spring JDBC

    في هذا الفصل، سندرس البنية التالية:

    وهي نفس البنية التي سبق ذكرها. سنقوم بإدخال تعديلين:

    • ستحتوي قاعدة البيانات على جدولين مرتبطين بعلاقة مفتاح أجنبي؛

    4.2. قاعدة البيانات [dbproduitscategories]

    قاعدة البيانات [dbproduitscategories] هي امتداد لقاعدة البيانات [dbproduits] التي تمت دراستها سابقًا. وفي حين أن المنتج في الجدول [PRODUITS] كان له فئة محددة برقم لا يحمل أي معنى خاص، فإن هذا الرقم هنا سيكون مفتاحًا خارجيًا في الجدول [CATEGORIES].

    الجدول [PRODUITS] هو كما يلي:

    • [ID]: المفتاح الأساسي الذي يتم زيادة قيمته تلقائيًا في الجدول [2]؛
    • [NOM]: الاسم الفريد للمنتج [4]؛
    • [PRIX]: سعر المنتج؛
    • [DESCRIPTION]: وصف المنتج؛
    • [VERSIONING] هو رقم إصدار المنتج. إصداره الأولي هو 1 [3]. في كل مرة يتم فيها تعديل المنتج، سيتم زيادة رقم إصداره بواسطة البرنامج الذي يستخدم الجدول؛
    • [CATEGORIE_ID]: المفتاح الخارجي في الجدول [CATEGORIES] لتحديد الفئة التي ينتمي إليها المنتج؛
    • في [1-3]، المفتاح الأجنبي [CATEGORIE_ID] من الجدول [PRODUITS]. وهي تستهدف العمود [ID] في الجدول [CATEGORIES] [4-5]؛
    • عند حذف فئة ما، يتم حذف جميع المنتجات المرتبطة بها أيضًا [6]. من المهم ملاحظة هذه النقطة لأنها تُستخدم في إنشاء الطبقة [DAO] التي تستفيد من قاعدة البيانات [dbproduitscategories]؛

    جدول الفئات [CATEGORIES] هو كما يلي:

    • [ID]: المفتاح الأساسي الذي يتم زيادة قيمته تلقائيًا؛
    • [VERSIONING]: رقم إصدار الفئة؛
    • [NOM]: الاسم الفريد للفئة؛

    4.4. تكوين Spring

      

    الفئة [AppConfig] التي تهيئ مشروع Spring هي كما يلي:

    
package spring.jdbc.config;

import generic.jdbc.config.ConfigJdbc;

import org.apache.tomcat.jdbc.pool.DataSource;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.ComponentScan;
import org.springframework.context.annotation.Configuration;
import org.springframework.context.annotation.Import;
import org.springframework.jdbc.core.namedparam.NamedParameterJdbcTemplate;
import org.springframework.jdbc.core.simple.SimpleJdbcInsert;
import org.springframework.jdbc.datasource.DataSourceTransactionManager;
import org.springframework.transaction.PlatformTransactionManager;
import org.springframework.transaction.annotation.EnableTransactionManagement;

@Configuration
@ComponentScan(basePackages = { "spring.jdbc.dao" })
@EnableTransactionManagement
@Import({ generic.jdbc.config.ConfigJdbc.class })
public class AppConfig {

    // مصدر البيانات
    @Bean
    public DataSource dataSource() {
        // مصدر البيانات TomcatJdbc
        DataSource dataSource = new DataSource();
        // تكوين الوصول JDBC
        dataSource.setDriverClassName(ConfigJdbc.DRIVER_CLASSNAME);
        dataSource.setUsername(ConfigJdbc.USER_DBPRODUITSCATEGORIES);
        dataSource.setPassword(ConfigJdbc.PASSWD_DBPRODUITSCATEGORIES);
        dataSource.setUrl(ConfigJdbc.URL_DBPRODUITSCATEGORIES);
        // الاتصالات المفتوحة في البداية
        dataSource.setInitialSize(5);
        // النتيجة
        return dataSource;
    }

    // مدير المعاملات
    @Bean
    public PlatformTransactionManager transactionManager(DataSource dataSource) {
        return new DataSourceTransactionManager(dataSource);
    }

    // JdbcTemplate
    @Bean
    public NamedParameterJdbcTemplate namedParameterJdbcTemplate(DataSource dataSource) {
        return new NamedParameterJdbcTemplate(dataSource);
    }

    // إدراج المنتج
    @Bean
    public SimpleJdbcInsert simpleJdbcInsertProduit(DataSource dataSource) {
        return new SimpleJdbcInsert(dataSource).withTableName(ConfigJdbc.TAB_PRODUITS).usingGeneratedKeyColumns(
                ConfigJdbc.TAB_PRODUITS_ID);
    }

    // إضافة فئة
    @Bean
    public SimpleJdbcInsert simpleJdbcInsertCategorie(DataSource dataSource) {
        return new SimpleJdbcInsert(dataSource).withTableName(ConfigJdbc.TAB_CATEGORIES).usingGeneratedKeyColumns(
                ConfigJdbc.TAB_CATEGORIES_ID);
    }

}

    4.5. استثناءات المشروع

      

    لقد سبق أن تناولنا الفئات [UncheckedException, DaoException, ShortException] في المشروع [spring-jdbc-03]. ونضيف فئة جديدة:

    
package spring.jdbc.infrastructure;

public class MyIllegalArgumentException extends UncheckedException {

    private static final long serialVersionUID = 1L;

    // الشركات المصنعة
    public MyIllegalArgumentException() {
        super();
    }

    public MyIllegalArgumentException(int code, Throwable e, String className) {
        super(code, e, className);
    }

}
    • تشتق الفئة [MyIllegalArgumentException] من الفئة [UncheckedException]، وبالتالي فهي فئة غير خاضعة للتحكم. وستُستخدم للإبلاغ عن استدعاء بأرجومنتات غير صحيحة لأحد أساليب الطبقة [DAO]. لم نسمها [IllegalArgumentException] لأن هذا الاستثناء موجود بالفعل في JDK، وكان ذلك يؤدي أحيانًا إلى قيام المُجمِّع بإنشاء [import] غير صحيح؛

    4.6. كيانات المشروع

      

    الفئات الموجودة في الحزمة [spring.jdbc.entities] هي تمثيلات لصفوف جداول قاعدة البيانات [dbproduitscategories]. وسنتجاهل في الوقت الحالي تمثيلات جداول [USERS, ROLES, USERS_ROLE].

package spring.jdbc.entities;

public abstract class AbstractCoreEntity {
    // الخصائص
    protected Long id;
    protected Long version;

    // الشركات المصنعة
    public AbstractCoreEntity() {

    }

    public AbstractCoreEntity(Long id, Long version) {

        this.version = version;
    }

    public AbstractCoreEntity(AbstractCoreEntity entity) {
        this.id = entity.id;
        this.version = entity.version;
    }

    public void setAbstractCoreEntity(AbstractCoreEntity entity) {
        this.id = entity.id;
        this.version = entity.version;
    }

    // ------------------------------------------------------------
    // إعادة تعريف [equals] و [hashcode]
    @Override
    public int hashCode() {
        return (id != null ? id.hashCode() : 0);

    @Override
    public boolean equals(Object entity) {
        if (!(entity instanceof AbstractCoreEntity)) {

        String class1 = this.getClass().getName();

        AbstractCoreEntity other = (AbstractCoreEntity) entity;
        return id != null && other.id != null && id.equals(other.id);
    }

            }
        }
        // النتيجة
        return cats;

            for (Categorie categorie : entities) {

                    updateCategories.add(categorie);

    هذه النتائج قد تكون مفاجئة في بعض الأحيان:

    • كان الحصول على النسخة الطويلة للمنتجات (perf09) أسرع من الحصول على النسخة المختصرة (perf08)، على الرغم من أن النسخة الطويلة تتطلب إجراء عملية ربط بين جدولين؛
    • تتجاوز مدة عملية التعبئة الأولى (perf01) بشكل واضح مدة جميع عمليات التعبئة الأخرى التي ستليها؛
    • يستغرق طلب النسخة المختصرة من المنتجات عبر أسمائها (perf08) وقتًا أطول من طلبها عبر المفاتيح الأولية (perf10). ويبدو هذا منطقيًا إلى حد ما. لكن بالنسبة للنسخ الطويلة، فإن العكس هو الصحيح (perf09، perf11)؛

    • [Spring JDBC]، والحلول الخمس الأخرى SGBD؛
